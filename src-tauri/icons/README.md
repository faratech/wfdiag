# Icons Required

Place the following icon files in this directory:

- 32x32.png
- 128x128.png
- 128x128@2x.png (256x256)
- icon.icns (macOS)
- icon.ico (Windows)

You can generate these from a single high-resolution PNG using:
- https://github.com/tauri-apps/tauri/tree/dev/tooling/bundler/src/bundle/windows/templates/icon.ico
- Online converters like https://convertio.co/png-ico/
