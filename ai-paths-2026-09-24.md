## Verified sound (highlights)

- Routing: `AUTO_FALLBACK_ORDER` exact; explicit preference never falls back (tested at
  every entry point); trust zones gate cloud transitions; consent Ask/Allow/Never with
  write-failure reprompt; `tried`-list termination guarantees.
- Request shapes: Anthropic `max_tokens` always present, no temperature, refusal-first;
  Gemini header auth, `"model"` role, object `functionResponse`, 17 safety reasons →
  Refusal; DeepSeek thinking disabled + `[DONE]` required; no token cap on compat wires;
  key redaction in Debug; keys never in URLs.
- Timeouts strictly nested: 180s turn > 150s CLI / 170s ACP prompt / 120s one-shot HTTP
  / 45s tools; 2 MiB SSE budget; 8 MiB bridge drains; single-terminal guarantees per worker.
- Credential handling: DPAPI per-provider storage, key-set booleans for availability,
  `skip_serializing` keys, presence-only CLI credential peeks.
- Phi: identity gate fails closed beneath every layer; 150s generation < 180s turn;
  15-minute prep budget honours cancellation; LAF token changes take effect on the next
  attempt without restart.
