Version 2.5.6 adds live model discovery across supported AI providers, so model choices stay current without waiting for an application update. The searchable model picker now shows friendly names, exact model IDs, and descriptions, including current Anthropic Claude, Google Gemini, OpenAI, and provider-reported GPT-5.6 families.

This update also adds clearer requested-versus-reported model attribution, improves automatic provider fallback, consolidates redundant AI settings, and expands subscription-based Codex CLI and Claude Code support. Additional improvements include safer approval-gated AI repairs, more accurate restart detection, a DISM deep health scan, stronger Processes, History, and Monitor workflows, and a refreshed Windows 11 acrylic interface.
